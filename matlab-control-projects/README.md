# MATLAB Control & Dynamics Portfolio
This repository contains MATLAB control-system projects in total 4 projects.

Four beginner-friendly control and dynamics projects written in MATLAB. Each project contains a mathematical model, open-loop analysis, a feedback controller, performance metrics, and plots that can be used in a GitHub portfolio or short university presentation.

## Projects

1. **Mass-Spring-Damper Position Control** — second-order mechanics + PID control.
2. **DC Motor Speed Control** — electromechanical modeling + PID speed control.
3. **Vehicle Cruise Control** — first-order vehicle dynamics + PI control + disturbance rejection.
4. **Inverted Pendulum Angle Control** — unstable dynamics + PD stabilization.

## Requirements

- MATLAB
- Control System Toolbox

## How to run

Open MATLAB, change the Current Folder to one of the project directories, and run the main `.m` file. Each script prints useful information in the Command Window and saves its figures in a local `figures` folder.

## Suggested GitHub workflow

You can keep this as one repository or make each numbered folder its own repository. For a portfolio, separate repositories can make each project easier to showcase.

## Learning goals

- Convert differential equations into transfer functions.
- Inspect poles and open-loop behavior.
- Design simple P/PI/PD/PID controllers.
- Compare transient-response metrics.
- Understand disturbance rejection and stabilization.
